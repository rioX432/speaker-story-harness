# Visual evidence that serves the narrative

Adapted from `deck-figure`. First define the exact slide claim and what the audience needs to see to understand it: shape, flow, difference, temporal change, measured comparison, relevant code, product demonstration.

Use diagrams, readable data, actual output or code selectively. A graphic made of long paragraphs is another slide disguised as a picture. Put the main evidence as large as possible, give meaningful labels and units, and avoid an unnecessary explanatory side column. Do not invent sources or graphical representations of unmeasured metrics.

Use real rendering at projected size, check crop, overlap, chart interpretations, legends, source URLs and videos with a still fallback for PDF. The picture and spoken script must refer to the same object at the same time.
