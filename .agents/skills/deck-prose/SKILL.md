# Speakable assertions

Ported in principle from `deck-prose`. Decide each slide's **new assertion** as one sentence, say it aloud, then choose the evidence needed to make that claim understandable. Keep key numerical units, comparison conditions, definitions and visual labels visible. Do not bury explanatory prerequisites in notes alone.

Write the spoken script like natural speech, not a formal paper. Do not repeat a takeaway band on every slide or fill slides with production labels. Place measured limitations only where they change the assertion or decision; remove irrelevant self-defeating disclaimers while preserving factual truth.

Prefer meaningful transitions over stock phrases: the next scene should resolve the question created by the last scene. After editing run `deck-audit`; re-check naturalness, numerical claims and displayed/speaking alignment.
